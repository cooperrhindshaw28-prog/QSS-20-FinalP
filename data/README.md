# Data

This project uses publicly available replication data from the GiveDirectly unconditional cash transfer experiment in rural Kenya.

The main dataset used in the analysis is:

`UCT_FINAL_CLEAN.dta`

The raw replication files are stored in the `dataverse_files/` folder.

The original data come from the public replication materials for:

Haushofer, Johannes, and Jeremy Shapiro. 2016.  
“The Short-Term Impact of Unconditional Cash Transfers to the Poor: Experimental Evidence from Kenya.”  
*The Quarterly Journal of Economics*, 131(4): 1973–2042.

The data are publicly available through the study's Dataverse repository.
